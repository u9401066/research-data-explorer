# Wide repeated-measures contract

`run_repeated_measures` accepts ordered comma-separated measurement columns and an optional `subject_variable`. A supplied subject column must be present, separate, nonempty and unique across all rows. Each row represents one independent subject; this is a within-subject time comparison, not a treatment-by-time model. Workbench requires the subject column and limits the prespecified study to 2–8 occasions.

Two occasions use two-sided SciPy Wilcoxon (`method=auto`, `zero_method=wilcox`, no continuity correction or implicit rounding); three or more use tie-corrected Friedman with a chi-square approximate p-value. Friedman uses the shared complete cohort. Only a significant omnibus test opens all k(k−1)/2 pairwise Wilcoxon tests with Bonferroni; `posthoc_case_strategy` explicitly chooses shared-complete or pairwise-complete cases. Signed change and rank-biserial r both use the later-listed occasion minus the earlier-listed occasion. All-zero paired differences have an explicit W=0, p=1, r=0 convention. Friedman with no within-subject variation fails as non-estimable.

Every selected value is checked before numeric plausibility masking. Invalid numeric text and infinity fail instead of being converted to missing. The existing BMI/height/weight rules apply to both inference and plotting. Durable receipts include engine version, policies, observed and excluded data-row positions, positional availability bitmasks, subject-order hash, plausibility exclusions, per-comparison n, and a receipt SHA256. Data row 1 is the first record after the header; retain the exact source file and selected sheet.

An explicit `scope: repeated-wide-v1` on both locked plan entries selects the repeated-study report contract: exactly one `run_repeated_measures` entry followed by its `visualization` entry, matching ordered variables and subject column, no extra figure tests, labels and outcome/unit axis, and fixed PNG filename. The top-level policy must match the analysis alpha, listwise omnibus cohort and Bonferroni correction. Scoped execution rejects different test arguments. The report checks the receipt digest, approved arguments, subject/case coverage, finite estimates, post-hoc family and denominators, PNG hash and rendering arguments, data quality, and actual report content. It does not add independent-sample models merely to satisfy a generic EDA count.

`create_visualization` accepts `subject_variable`, ordered `labels`, and `ylabel`. With `include_tests=false`, paired and line plots describe complete cases without an additional p-value. Explicit exploratory line tests use Friedman for 3+ occasions; an independent Kruskal test is inappropriate for these paired values. All visualization manifests now retain actual PNG hashes and rendering arguments.

Assumptions remain a researcher responsibility: independent subjects, suitable measurement scale and symmetric paired differences for Wilcoxon. Friedman chi-square p-values have limited reliability with n ≤ 10 or ≤ 6 occasions. Neither complete-case deletion nor plausibility filtering proves absence of selection bias. No effect-size confidence interval, exact Friedman inference, mixed model, cluster/crossover effect or causal treatment effect is provided by this contract.

Primary references: [SciPy Wilcoxon](https://docs.scipy.org/doc/scipy-1.16.2/reference/generated/scipy.stats.wilcoxon.html), [SciPy Friedman](https://docs.scipy.org/doc/scipy-1.16.2/reference/generated/scipy.stats.friedmanchisquare.html). Validation used SciPy 1.16.3; numerical tests include independent sign enumeration and a closed-form chi-square survival reference.

Regression coverage: `tests/test_repeated_contract.py`, `tests/test_report_contract.py`, and Workbench's real CSV/XLSX MCP integration tests. Version remains 0.5.0.
