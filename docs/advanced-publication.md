# 通用探索的可追溯投稿圖（開發分支）

新執行且完成來源綁定的通用探索，可從保存數值生成 PNG、PDF、SVG、TIFF、
繪圖 CSV 與英文圖說／中文解釋。`render_branch_publication` 接受原生 `br_*`、
`exp_*` 及分析 JSON 的精確 SHA256，另存期刊版次。正式站部署與 Workbench
投稿面板接線仍需另行驗收；本文件不代表已部署。

## 分析與呈現

- Logistic：截距另圖，因素 OR 使用對數間距與原比值刻度；保留全部係數、
  區間及對照編碼。極寬區間不任意截斷，超出浮點表示的刻度明示 `exp(value)`。
  已保存的建模機率按結果組內排序；此圖不是校準圖或外部預測驗證。
- 線性迴歸：截距另圖，全部因素係數與區間、觀察／擬合值及 response residual。
  不重擬合平滑線或新做檢定。regularized fallback 保留真正的中心化／標準化
  尺度與無一般推論的限制，不補造缺少的信賴區間。
- 事件比例：各組事件分子／分母，以及 RD、RR、OR 的獨立尺度圖。使用保存的
  Newcombe–Wilson 或 log-Wald 區間；零格或不可估計時明示不可用。這是未調整的
  二元事件比較，沒有處理設限或建立固定時間風險；病例對照抽樣不能據此解讀風險。
- 傾向分數：全部分數的組內累積分布、觀察／IPTW／匹配階段的 SMD、全部穩定化
  ATE 權重與每一對配對距離。各階段使用各自 pooled SD，不能稱為固定分母下的
  平衡改善。配對、clipping、caliper 與限制範圍沿用保存政策，不重跑或暗中截尾。
  分組是模型結果，沒有估計臨床終點效果，也不宣稱因果識別。

每份研究皆有完整個案納排圖與全列 CSV。輸入位置和正規化來源 index 保留，
不能當作實體 CSV 行號；先前核准的補值由清理收據說明。各方法依真正使用欄位
處理缺值，不能宣稱與主要分析或其他模型的個案相同。

所有係數與分類層級分頁保留，沒有只畫前幾個因素。字典可提供這次契約的原始
結果、組別及共變項英文標籤；單位是原始尺度的人工說明，不換算任何數值。
改圖說仍保留探索性、多重探索、方法限制、來源尺度與字典聲明。

## 證據與失敗行為

分析 JSON 的 `analysis_result` 是完整原始數值，`publication_result` 是凍結的
繪圖輸入，`figures` 與 `artifacts` 綁定六格式原圖及完整報告。原數值收據、
圖稿輸入與整份檔案各有獨立 SHA256。程式核對真正使用的結果、因素與信賴水準，
完整列數／位置及配對身分。只檢查 hash 不代表臨床假設或研究設計正確。

出圖與同 UUID 取回皆先檢查唯一、已完成的兩份原生 ledger，以及完整來源與
圖表產物。來源快照、清理收據、圖表、報告或執行紀錄變更即拒絕；不靠重估模型
掩蓋損壞。原上傳檔不在時仍可核對保存的原檔快照，後續清理不重寫歷史版次。
記憶體資料或未具備此完整 bundle 的舊探索不具有投稿來源資格。

分支採用／丟棄／待評讀仍是另一個決定，成功出圖不採納分支或修改主要計畫。
LLM 評讀仍須獨立語意核對，不能因圖表 hash 通過就宣稱研究文字正確。

## 驗證範圍

邊界測試包含零事件組、regularized 缺區間、完整 1,202 列及 601 對匹配、來源／
ledger 損壞、重複 ledger、移除上傳檔後取回、不重新載入／擬合，以及 Nature
單欄和 PLOS 欄寬下的長字典標籤與圖說覆寫。完整外部 MCP 另以 UCI 519 的
299 列公開資料執行四方法、另存版次及字典／期刊圖版；這是指定方法的工程
驗證，不宣稱自主發現新的臨床結論。整體測試與逐頁視覺審閱結果記於平台進度。
